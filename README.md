# ZeroFrame

공강에 노트북을 들고 실습실까지 갔는데 자리가 없었던 적이 있나요? ZeroFrame은 경북대학교 컴퓨터학부 학생이 과방이나 실습실에 가기 전에 휴대폰으로 빈자리를 확인할 수 있도록 기획한 해커톤 프로젝트입니다.

## 학생 화면은 이렇게 읽습니다

**제1실습실 · 빈자리 1 / 전체 4석 · 확인 불가 1석**

아래는 화면을 설명하기 위한 가상의 좌석 배치입니다.

| 창가 쪽 | 통로 쪽 |
| --- | --- |
| A1 · 빈자리 · 콘센트 있음 | A2 · 사용 중 |
| B1 · 짐 있음 | B2 · 확인 불가 |

노트북을 충전하고 싶은 학생은 A1을 눌러 마지막 확인 시각을 보고 실습실로 이동할지 결정합니다. 카메라가 B2를 제대로 볼 수 없다면 그 자리는 ‘확인 불가’로 표시합니다. 학생에게 전달하는 정보는 좌석도와 상태이며, 카메라 영상은 장치 안에서만 처리하도록 설계했습니다.
